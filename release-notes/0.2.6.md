- **Real docking.** Windows snap together, and to the screen's edges, when you drag them close. Drag the Main Window and everything docked to it comes along; drag the Equalizer or Playlist on its own to pull it away, and drop it back to dock it again.
- When a window changes height (Windowshade, resizing the Playlist), the windows docked under it follow.
- Double Size scales the whole stack, keeping it together.
- The Equalizer and Playlist remember where you put them, and minimizing the Main Window takes them along.
