- **Intel One Mono**, bundled. The Library's lists use it, and BitMachine ▸ Settings ▸ Fonts can draw the Main Window's song title in it too: sharp on Retina, in your skin's colours, and with every character, so accents, Japanese and the rest show up properly. The skin's pixel font stays the default for the title. Prefer your skin's own Playlist font for the lists? There's a switch for that.
