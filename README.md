# BitMachine

A skinnable music player for Apple Music, your files and your Navidrome server

## Install

```sh
brew install --cask phin-tech/tap/bitmachine
```

Or download the zip from the [latest release](https://github.com/phin-tech/bitmachine/releases/latest).
BitMachine updates itself.

## Develop

```sh
just build   # needs Xcode and xcodegen
just test
```

See [DEVELOPMENT.md](DEVELOPMENT.md).
